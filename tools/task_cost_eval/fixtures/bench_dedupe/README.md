Implement `dedupe_records(records, key, *, casefold=False)` in `dedupe.py` using only the Python standard library. It walks records in input order, calls `key(record)` once per record, keeps the first record for each key, optionally normalizes keys with Unicode `str.casefold()`, and returns a new list of shallow dict copies so callers cannot mutate the originals. `key` must be callable and return a `str`; records must be an iterable of dicts; `casefold` must be a bool. Raise `ValueError` for invalid input. Run `PYTHONDONTWRITEBYTECODE=1 python -m unittest discover -v` from this slice.
