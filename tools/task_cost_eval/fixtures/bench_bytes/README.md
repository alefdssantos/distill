Implement human-readable byte-size parsing and formatting in `sizes.py` inside this slice, using only the Python standard library and Python 3.11+. Keep the existing function signatures.

`parse_size(text)` accepts a string, strips surrounding whitespace, and requires exactly one ASCII space between a decimal number and a unit. The number is one or more ASCII digits with an optional single dot followed by at least one ASCII digit; leading zeros are accepted. Units are case-sensitive: `B`, `KB`, `MB`, `GB`, `TB` are decimal multiples of 1000, while `KiB`, `MiB`, `GiB`, `TiB` are binary multiples of 1024. Convert with exact rational arithmetic and return an `int` number of bytes. If the exact result is not a whole number of bytes, raise `ValueError` (`0.5 B` and `1.1 KiB` are invalid, `0.5 KiB` and `1.1 KB` are valid). Reject non-`str` values, empty strings, signs, plus signs, exponents, underscores, commas, internal tabs, multiple spaces, lowercase or abbreviated units, unknown units, and non-ASCII digits with `ValueError`.

`format_size(num_bytes)` accepts a non-negative `int` and returns a compact human string using decimal units only: choose the largest of `B`, `KB`, `MB`, `GB`, `TB` that does not exceed the value, write at most two fractional digits rounded half up, strip trailing zeros and a trailing dot, and separate the number from the unit with exactly one space. If rounding reaches 1000, promote to the next unit. Bytes below 1000 use unit `B` with no decimal part, and zero is `0 B`. Examples: `format_size(10)` is `10 B`, `format_size(1536)` is `1.54 KB`, `format_size(2000000)` is `2 MB`, and `format_size(999999)` is `1 MB`. Reject `bool`, floats, strings and negative integers with `ValueError`. Formatting is compact and deterministic; it need not round-trip every arbitrary byte count exactly because of the two-digit display limit.

Both functions are pure, never mutate input, ignore no locale, and are case-sensitive. Do not rely on mapping iteration order. Run `PYTHONDONTWRITEBYTECODE=1 python -m unittest discover -v` from this slice.
