Implement `encode_cursor`, `decode_cursor`, and `paginate` in `cursors.py` using only the Python standard library. A cursor is the unpadded base64url encoding of the UTF-8 JSON array `[created_at, id]` produced with `json.dumps(..., ensure_ascii=False, separators=(',', ':'))`; decoding validates the alphabet, padding, UTF-8, payload shape, types, and canonical form. Pagination sorts records by `(created_at, id)` descending, returns at most `limit` records strictly after the cursor, and returns the cursor of the last emitted record or `None` on the final page. Invalid input raises `ValueError`. Run `PYTHONDONTWRITEBYTECODE=1 python -m unittest discover -v` from this slice.
