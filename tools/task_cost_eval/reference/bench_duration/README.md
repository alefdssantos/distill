Implement ISO-8601 duration parsing and canonical formatting in `duration.py` inside this slice, using only the Python standard library and Python 3.11+. Keep the existing function signatures.

`parse_duration(text)` returns total seconds. Accepted grammar is uppercase ASCII only: either `P<number>W` (weeks, alone, no `T` part), or `P` followed by an optional `<number>D` and an optional `T` part containing `<number>H`, `<number>M` and `<number>S` in that order. Each number is one or more ASCII digits with an optional fractional part introduced by a dot and at least one digit. At least one component must be present, and a `T` must be followed by at least one time component. A decimal fraction is allowed only in the last component that appears; components before it must be integers. Units convert as weeks 604800, days 86400, hours 3600, minutes 60, seconds 1. Return an `int` when the total is a whole number of seconds, otherwise a `float`; `PT0.5S` returns `0.5` and `P1DT2H3M4S` returns `93784`. Leading zeros are accepted. `P0D` and `PT0S` are valid and return `0`.

Validation is strict: reject non-`str` input, empty strings, lowercase or mixed-case designators, leading or trailing whitespace, signs, underscores, commas, exponent notation, repeated or out-of-order components, years or months (`Y` and date `M`), mixing `W` with other components, an empty `T` part, decimal fractions in non-final components, and a dot without following digits. Raise `ValueError` for every invalid input.

`format_duration(seconds)` accepts a non-negative `int` or finite `float` and returns canonical ISO-8601 using days, hours, minutes and seconds (never weeks): `P<days>D` when days are present, then `T<hours>H<minutes>M<seconds>S` including only non-zero components except that zero total is exactly `PT0S`. Seconds may carry a fractional part of at most six decimal places, written without trailing zeros. Whole values use no decimal point. Reject `bool`, non-numeric values, negative values, non-finite floats and values with more than six fractional digits with `ValueError`. Formatting then parsing must return the same value for every accepted input.

Both functions are pure and deterministic; never mutate input and do not rely on mapping iteration order. Case is significant: designators must be uppercase ASCII. Run `PYTHONDONTWRITEBYTECODE=1 python -m unittest discover -v` from this slice.
